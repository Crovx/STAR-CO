# STAR/CO — Estudio Digital Monolítico & Experiencia 3D

> Plataforma web de alta conversión y estudio digital en Torreón. Objetos 3D interactivos con Three.js, diseño web de alto impacto, automatizaciones con IA, reseñas en Google Maps por celular y menús digitales cloud.

## 🚀 Tecnologías
- **HTML5 & Tailwind CSS** (Arquitectura monolítica y diseño responsivo)
- **Three.js / WebGL** (Escena 3D interactiva, estrella geodésica, anillos giroscópicos y partículas de polvo estelar)
- **Web Audio API** (Sintetizador generativo de audio espacial cósmico)
- **Vercel** (Despliegue serverless de alta velocidad)

## 📦 Estructura del Proyecto
```
STARCO/
├── index.html          # Página principal y estructura DOM
├── style.css           # Estilos base y variables de diseño
├── vercel.json         # Configuración de despliegue en Vercel
├── .gitignore          # Archivos ignorados por Git
└── js/
    ├── app.js              # Controlador principal y ciclo de eventos
    ├── scene3d.js          # Escena Three.js, cámara, renderer y luces
    ├── star.js             # Geometría 3D de la estrella geodésica y anillos
    ├── floatingElements.js # Elementos flotantes 3D en el espacio
    ├── particles.js        # Sistema de partículas estelares
    └── audio.js            # Generador Web Audio API
```

## 🌐 Despliegue en Vercel
1. Conecta este repositorio a [Vercel](https://vercel.com/).
2. Framework Preset: **Other** / **Static Site**.
3. Root Directory: `./`.
4. Haz clic en **Deploy**.
